The first release of **Sanguine City**: an online vampire sandbox built in Unity. It draws on what is publicly known about CCP Games' cancelled *World of Darkness* MMO: a politics-first sandbox with open PvP, a secrecy mechanic, feeding on humans and minion missions. The setting, names and rules are original.

This is a playable **prototype**, so it is marked as a pre-release.

## Downloads

| File | What it is |
|---|---|
| `SanguineServer-v0.1.0-linux-x64.tar.gz` | Dedicated server for Linux: one self-contained executable, no .NET install needed |
| `SanguineServer-v0.1.0-win-x64.zip` | The same for Windows |
| `SHA256SUMS.txt` | Checksums for both |

Run the server with `./SanguineServer --port 7777` (`SanguineServer.exe` on Windows). `--help` lists the options: port, city seed, save folder, night and day length, mortals, player cap. Type `status` or `quit` in its console.

**The game client** comes from the source code below. Open the project in Unity 6 (6000.0 LTS) or 2022.3.67+, press Play, and choose *Host & Play* or *Join Server*. Player builds are made from the editor's **Sanguine ▸ Build** menu. Client builds aren't attached, because building them needs a Unity licence. Client and server must both be this version (network protocol 6).

## What's in it

- **Six bloodlines with three gifts each.** The first gift is innate; the others are learned by spending standing.
  - **Vorlen:** Surge, Iron Skin, Earthshaker.
  - **Sylphine:** Allure, Glamour, Rapture.
  - **Ashborn:** Blood Lash, Siphon, Crimson Mist.
  - **Aurum:** Command, Majesty, Dominate.
  - **Umbren:** Shroud, Whispers, Undercroft.
  - **Varga:** Pounce, Pack Howl, Unchained.
- **Sires and childer.** A fledgling can accept the Embrace from an elder and join their bloodline.
  - The sire teaches gifts for less standing and answers for the childe's crimes until releasing them.
  - Sire and childe can't harm each other and are stronger side by side.
  - The family shares a chat channel.
- **Feeding** on a living crowd of mortals, and the choice to release them in time or let them die. **Conscience** falls with every death, until the Beast takes over.
- **The Hush:** witnesses raise your exposure. Hunters come at 50%, and at 80% any vampire may kill you.
- **Open PvP** with consequences (Outlaw, Marked), safe havens, neutral sanctums, and a night/day cycle in which the sun burns.
- **Politics:** circles, thrall missions that win district control, a nightly Regent election, edicts and blood hunts.
- **An authoritative server** that runs embedded in the client, inside a headless Unity build, or standalone (these downloads). Characters, lineages, circles, influence and the Regent persist.
- **Realistic CC0 art** (Poly Haven and ambientCG) in a rain-wet night city with about 390 real lights and post-processing.
- **An original synthesised soundscape:** ambience, rain, score, footsteps, and cues for every gift and for the Embrace.

## Verification

- The integration test (`Server/Tests`) runs a real server against six scripted bot clients over TCP: 99 checks covering every system above, including persistence across a restart. It passes on Mono and on .NET 8, and this release was only published after it passed.
- The Unity client is compile-checked against Unity's assemblies.

## Known limitations

- The newest client features have not been play-tested inside the Unity editor yet: the lineage panel, the Embrace prompt, and the Shroud and Unchained effects.
- There are no realistic human characters yet. Articulated fallback figures are used, and any humanoid models you add are picked up automatically.
- Transport is TCP and persistence uses flat files, so this isn't built for MMO scale. WebGL is not supported.
- Movement is client-predicted. The server checks speed and building collision, but small props are only solid on the client.
